# Azure Concord — player site

The players' view of the Three Roads campaign: each player picks their character and sees their full sheet, the party's headline stats, party loot, the shop ledger, the Odranard Guild, and the session journal.

- `index.html` — the site (no build step).
- `data.json` — the player-safe snapshot the site reads. It is regenerated by the DM before each session.
- `tools/export_players.py` — builds `data.json` from the DM ledger and keeps only whitelisted fields, so DM-only material never reaches this public repository.

Everything in this repository is public, including its history. Never commit raw DM data.
